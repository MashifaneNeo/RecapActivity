# Holiday Showdown

Topic
Public holidays comparison — powered by date.nager.at public API.

## What it does
Holiday Showdown lets you pick two countries and a year, fetches the live
count of public holidays for each from date.nager.at, and tells you which
country wins, or if it's a tie. 

## The three screens
1. **Compare** — choose Country A, Country B, and a year; fetch live data.
2. **Result** — side-by-side live values, verdict, and combined total.
3. **History** — ranked leaderboard.

## Personal feature
**Favourites list** — from the Result screen you can star the winning
country into a Favourites leaderboard (`RankedList<HolidayCount>`), shown
underneath the main history on Screen 3.

## Data source
https://date.nager.at.
